# 1. 🔀 Git

![Git](https://img.shields.io/badge/Git-red?logo=git)

### Purpose

**Git** is a distributed version control system used to track changes in source code and collaborate with other developers.

### Official Website

[Visit Git Official Website](https://git-scm.com/)

### Common Command

```bash
git status
```

The `git status` command shows the current state of the working directory and staging area.

> Git helps developers track and manage changes to their projects.

---

# 2. 🐳 Docker

![Docker](https://img.shields.io/badge/Docker-blue?logo=docker)

### Purpose

**Docker** is a platform used to build, package and run applications inside containers.

### Official Website

[Visit Docker Official Website](https://www.docker.com/)

### Common Command

```bash
docker ps
```

The `docker ps` command displays running Docker containers.

> Docker makes it easier to package applications with their dependencies.

---

# 3. ⚙️ Jenkins

![Jenkins](https://img.shields.io/badge/Jenkins-red?logo=jenkins)

### Purpose

**Jenkins** is an automation server commonly used for Continuous Integration and Continuous Delivery.

### Official Website

[Visit Jenkins Official Website](https://www.jenkins.io/)

### Common Command

```bash
jenkins --version
```

This command displays the installed Jenkins version.

> Jenkins can automate building, testing and deployment processes.

---

# 4. ☸️ Kubernetes

![Kubernetes](https://img.shields.io/badge/Kubernetes-blue?logo=kubernetes)

### Purpose

**Kubernetes** is an open-source platform used for deploying, scaling and managing containerized applications.

### Official Website

[Visit Kubernetes Official Website](https://kubernetes.io/)

### Common Command

```bash
kubectl get pods
```

This command displays the pods running in a Kubernetes cluster.

> Kubernetes helps manage containerized applications at scale.

---

# 5. ☁️ AWS

![AWS](https://img.shields.io/badge/AWS-orange?logo=amazonaws)

### Purpose

**Amazon Web Services (AWS)** is a cloud computing platform that provides services for computing, storage, databases, networking and more.

### Official Website

[Visit AWS Official Website](https://aws.amazon.com/)

### Common Command

```bash
aws --version
```

This command displays the installed AWS CLI version.

> AWS provides cloud infrastructure and services that can be used to build and deploy applications.
